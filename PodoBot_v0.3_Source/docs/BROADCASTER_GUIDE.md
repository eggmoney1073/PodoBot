# PodoBot 사용법

## 처음 한 번

1. `PodoBotSetup.exe`를 실행합니다.
2. 설치할 폴더를 고릅니다.
3. 설치 후 PodoBot을 실행합니다.
4. `치지직 연결하기`를 누릅니다.
5. 브라우저에서 치지직 연결을 승인합니다.

끝입니다.

## 방송할 때

PodoBot을 실행하고:

```text
방송봇 켜기
```

를 누릅니다.

상단에:

```text
방송봇 켜짐
```

이 보이면 준비 완료입니다.

## 명령어

`명령어` 탭에서 추가합니다.

예:

```text
명령어: !유튜브
답변: 유튜브 주소는 ...
사용 권한: 전체
```

## 룰렛

`룰렛` 탭에서 당첨 내용과 확률을 입력합니다.

예:

```text
꽝            50
물 마시기     30
한 번 더      20
```

합계가 반드시 100%여야 합니다.

기본 채팅 명령어는:

```text
!룰렛
```

입니다.

## 타이머

예:

```text
메시지: 팔로우와 알림 설정 부탁드립니다!
몇 분마다: 30
```

방송봇이 켜져 있는 동안 반복해서 전송됩니다.

## 카운터

예:

```text
이름: 사망
명령어: !사망
현재 값: 0
변화 값: 1
사용 권한: 매니저
```

매니저가 `!사망`을 입력하면 숫자가 1 올라갑니다.

## OBS 룰렛

OBS에서 `브라우저` 소스를 추가한 뒤 아래 주소를 입력합니다.

```text
http://localhost:18766/roulette
```

PodoBot이 켜져 있어야 화면이 동작합니다.
